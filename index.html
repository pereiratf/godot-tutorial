Para quem é este tutorial

  • Já programa em qualquer linguagem
  • Nunca usou uma game engine antes
  • Quer entender a lógica, não só copiar código
  • Pretende continuar o projeto além do tutorial

O que você vai construir

Um jogo de plataforma 2D completo em Godot 4 com C# — personagem com física de plataforma, inimigos com patrulha, coletáveis, sistema de vidas, HUD e exportação para desktop. A arquitetura é projetada para ser extensível.

Transparência sobre uso de IA

Este material foi criado com o auxílio do Claude (Anthropic). O conteúdo — estrutura dos módulos, textos explicativos, exemplos de código, desafios e prática guiada — foi gerado em colaboração entre o autor e a IA, revisado e curado pelo autor.

O uso de IA como ferramenta de criação de material didático é declarado intencionalmente. Dúvidas, correções ou sugestões podem ser enviadas diretamente ao autor.
